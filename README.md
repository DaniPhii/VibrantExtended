# Vibrant doZen for Amazfit Bip 6
Modification of `sb7`'s preinstalled watchface ported to `bip6` with additional features, including dozenal clocks inspired by [`doZen` created by coWen](https://apps.garmin.com/apps/96cab36a-7822-4e1d-8593-4649298c7431) and [this port for Amazfit Balance made by heartless](https://amazfitwatchfaces.com/balance/view/2543).

## How to build
Use [zmake](https://mmk.pw/en/zmake).
